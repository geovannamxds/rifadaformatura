# Rifa da Formatura da Geo

Página de vendas dos números da Rifa Formô 26.2.

- Site: https://geovannamxds.github.io/rifadaformatura/
- `index.html`: a página que os compradores veem.
- `estado.json`: configuração da rifa (preço, Pix, WhatsApp, prêmios, mensagens) e a lista de números que já têm dono. A página lê esse arquivo toda vez que abre, então basta atualizá-lo pra mudar a disponibilidade dos números.
- `og.png`: imagem que aparece quando o link é compartilhado no WhatsApp.

O controle das vendas (compradores, pagamentos, bilhetes) fica no painel da Geo dentro do Claude e não é publicado aqui: este repositório só tem os números ocupados, sem nomes nem telefones.
